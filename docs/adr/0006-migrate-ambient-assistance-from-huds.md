# Migrate ambient assistance from HUDs

The approved direction is to migrate the remaining Text assistant HUD flows to
text-bound interactions. That migration remains deferred; current HUDs stay in
place until each replacement is designed and verified.

This supersedes the standalone category-HUD direction in ADR 0001 and the ambient
HUD layout direction in ADRs 0002 and 0005 as each flow migrates. Their unrelated
policies remain in effect. This records a design decision, not completed work.
